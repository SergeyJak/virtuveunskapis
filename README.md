# Virtuve un Skapis MVP

Runnable Next.js MVP based on the approved premium digital-showroom concept.

## Run
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Included
- Home page
- Portfolio
- Project detail pages
- Contact page with local success state
- Responsive header and mobile menu
- Local concept-derived images
- SEO metadata
- Reusable data and components
