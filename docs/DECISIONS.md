# Decisions

- MVP is portfolio-first.
- No online price calculator.
- No public prices.
- Contact form is a frontend demo until backend is selected.
- Images are derived from the approved concept and must later be replaced with original company assets.
- Main language in MVP: Latvian.
- Stack: Next.js, TypeScript, custom CSS.
- Tailwind was removed to avoid unused tooling warnings while preserving the existing visual design and page structure.
